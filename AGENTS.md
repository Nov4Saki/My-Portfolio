# Developer & AI Agent Instructions

When adding new projects, editing existing project metadata, or updating portfolio content:

1. **Read `ADDING_A_PROJECT.md`** first. Follow its schema and strict rules.
2. **Never modify template files** (`index.html`, `project.html`, `assets/site.css`, `assets/site.js`).
3. Keep all project entries in `data/projects.js` with verified, factual data and bilingual `en`/`ar` strings.
4. Ensure all project screenshots are placed under `projects/<id>/` and contain only clean application visuals (zero desktop chrome or personal messages).
